## Web Lottie caveats
- `lottie-react-native` v7 web player needs `@lottiefiles/dotlottie-react`.
- AgendaLibre uses **platform split**: `SuccessLottie.tsx` (native Lottie) + `SuccessLottie.web.tsx` (Lucide FadeIn/ZoomIn).
- Web never imports `lottie-react-native` → Metro does not require DotLottie. Native falls back to Lucide on reduce-motion / animation failure.
